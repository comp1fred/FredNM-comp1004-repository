My project Title is Assist My Patient. My stand-up meeting leader is Vasileios Kelefouras.

The vision is to improve pharmacist to patient relations. The customer comes up to the counter with concerns or a prescription and the app which is designed for the pharmacist asks for :
- the patient's name
- phone number
- the date

The app will then unfolds a lists of common symptoms that the pharmacist may pick from (or an option to add one if the patient's case is special). 

After providing support and advice and the customer leaves, the app displays on the web page a calendar and a date for the pharmacist to call the patient and check up on their recovery or condition.

It will use an Alexa Skill for notifying the user via a Voice interface about the calls they need to  make.

The app will be able to read a JSON file to identify the number of time a call was made. 

Calculate the number of calls made in a given period of time. 

Be able to allow the pharmacist to choose between the option "answered" and "unanswered" after the call was made. 

The pharmacist may ask the patient to rate the service from 1 to 5 stars then input that answer in a star system rating within the app. (optional)
